# 🔥 SISTEMA DE PENTESTING REAL

**Sistema de pentesting que ejecuta herramientas REALES. Nada de simulaciones.**

## ⚔️ Herramientas REALES Incluidas

- **Nmap** - Escaneo de puertos y servicios
- **Nikto** - Escaneo de vulnerabilidades web
- **Gobuster** - Enumeración de directorios
- **SQLMap** - Detección y explotación SQL injection
- **Hydra** - Ataques de fuerza bruta
- **Metasploit** - Framework de explotación
- **Aircrack-ng** - Auditoría WiFi
- **John the Ripper** - Cracking de passwords
- **Hashcat** - Cracking avanzado
- **Y 30+ herramientas más**

## 🎯 Pentesting Automatizado

El sistema puede hacer pentesting completo automatizado:

1. **Reconocimiento** - Escaneo nmap completo
2. **Enumeración web** - Nikto + Gobuster si hay web
3. **SQL injection** - SQLMap automático
4. **Fuerza bruta** - Hydra en servicios encontrados
5. **Explotación** - Metasploit automático
6. **Payload** - Generación automática
7. **Reporte** - Resultados en JSON

## 📄 Resultados

Todos los resultados se guardan en:
- `/tmp/pentest_results_TIMESTAMP.json`
- Formato JSON con todos los outputs
- Fácil de procesar y analizar
