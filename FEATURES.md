## 🎯 Casos de Uso

### 1. Pentesting Corporativo
```bash
# Escaneo completo de infraestructura
sudo python main.py --target company.com --autonomous --scan-type comprehensive

# Phishing dirigido a empleados
sudo python main.py --phishing --target-email employee@company.com --phishing-template linkedin
```

### 2. Red Team Exercises
```bash
# Generación de malware personalizado
sudo python main.py --malware --malware-type backdoor --payload-format exe

# Campaña de phishing masiva
sudo python main.py --phishing --target-list employees.txt --phishing-template microsoft
```

### 3. Bug Bounty Hunting
```bash
# Reconocimiento masivo de subdominios
sudo python main.py --target bugcrowd-target.com --autonomous --scan-type web

# Búsqueda automatizada de vulnerabilidades
sudo python main.py --target scope.txt --autonomous --scan-type comprehensive
```

### 4. Investigación de Seguridad
```bash
# Análisis de malware en entorno aislado
sudo python main.py --malware --malware-type trojan --payload-format py

# Investigación OSINT automatizada
sudo python main.py --target person@company.com --autonomous --scan-type osint
```
